Easy Password Challenge
=======================

CONCEPT:
Use contextual clues from a fake user's social media profile (like Twitter/Facebook)
to discover their password. Posts contain personal/vulnerable information that
reveals the password pattern.

PASSWORD PATTERN: [PetName][BirthYear]
Example: Max1995, Bella1992, etc.

The username for the admin website is the @ of the user's profile (e.g., @emma_smith)

SESSION-BASED SYSTEM:
- Each visitor receives a unique session cookie
- Each session gets a DIFFERENT randomly generated profile
- Each session gets a UNIQUE flag in format: MaaSec{[a-f0-9]{16}_flag}
- Flags are generated using: MD5(SECRET + session_id).substring(0,16)

HOW TO RUN:
-----------
1. npm install
2. npm start
3. Visit http://localhost

ENDPOINTS:
----------
- /         : Shows the fake social media profile with clues
- /admin    : Admin login panel
- /reset    : Destroys session and generates new profile/flag
- /api/verify?flag=XXX : Verifies if flag is correct for current session

CLUES IN POSTS:
---------------
1. Post about pet mentions the pet's name
2. Birthday throwback post reveals birth year
3. Security tip post hints at password pattern (pet name + birth year)
4. Bio and other posts contain additional context

FILES:
------
- server.js           : Main Express application
- profileGenerator.js : Generates unique profiles per session
- views/profile.ejs   : Social media profile page
- views/login.ejs     : Admin login page
- views/success.ejs   : Flag reveal page
- package.json        : Dependencies

ENVIRONMENT VARIABLES:
----------------------
-- PORT        : Server port (default: 80)
- FLAG_SECRET : Secret for flag generation (change in production!)
